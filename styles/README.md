# Styles Directory

This directory is reserved for additional stylesheets and theme files.

## Current Styling Setup

The application currently uses:
- **Tailwind CSS** for utility-first styling
- **Global CSS** (`app/globals.css`) for base styles and custom utilities
- **Component-level styling** using Tailwind classes

## Adding Custom Styles

You can add custom stylesheets here and import them in your components or layouts as needed.

## Theme UI Integration

When you add your custom theme-ui folder, you can integrate it here or create a dedicated folder structure as needed.
